Built with HTML, CSS, JavaScript (frontend) and Java (Spring Boot), MongoDB (backend). Implemented interactive forms, user-friendly UI, and error handling features to ensure smooth functionality.

ORCA AI Project Details

ORCA AI – MCP-Based AI DevOps Automation Platform

Built an autonomous development system using the Model Context Protocol (MCP) to orchestrate multiple tools and AI agents. Integrated MCP clients for browser testing, deployment, GitHub automation, and shell execution in a unified workflow.

Developed multi-model AI orchestration using OpenAI, Anthropic, and Google with intelligent fallback handling. Implemented a self-healing pipeline where AI detects errors and automatically fixes generated code. Enabled end-to-end automation from prompt → code generation → deployment on Railway with live validation.
