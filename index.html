09 / ML & vision

ML & vision

Speech Emotion Recognition

Academic ML project

An audio classifier for eight emotions. Compares an ANN, CNN, and CNN–Transformer, then averages their predictions in an ensemble with a Streamlit demo.

PythonTensorFlowLibrosascikit-learnStreamlit
Project details
  • Uses 4,240 RAVDESS and TESS speech clips, MFCC features, and Mel-spectrograms. A four-person academic submission with CNN implementation and project coordination among Tarun’s contributions.
  • The project report records 92.3% ensemble accuracy on an 848-clip held-out test set. This is a clip-level split on acted speech; speaker-disjoint evaluation is not established.
